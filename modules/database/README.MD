# Database Module

Provisions an Azure SQL Database and its logical server, with the admin password generated by
Terraform rather than typed, stored in a file, or ever touched by a human. See ADR and
`CHALLENGES.md` entries on why Azure SQL Database was chosen over PostgreSQL for this project.

## What this creates

- One `random_password` resource — generates the SQL admin credential once, on first apply;
  the value is never written by a person and never appears in any `.tfvars` or config file
- One `azurerm_mssql_server` (the logical server / access point), using the generated password
  and with `public_network_access_enabled = false`
- One `azurerm_mssql_database` living inside that server

This module deliberately does not store the generated password anywhere on its own — it only
outputs it, sensitively. Storing it as an actual secret is the `key-vault` module's job, closing
the loop: generate here, store there, read only by whatever identity is explicitly granted access.

## Inputs

| Name | Type | Description |
|---|---|---|
| `resource_group_name` | `string` | Name of the resource group where database resources will be created |
| `location` | `string` | Azure region for the SQL server, independent of the other modules — some Azure trial subscriptions restrict SQL provisioning by region separately from other services, so this is intentionally decoupled. Defaults to `centralus`. |

## Outputs

| Name | Description |
|---|---|
| `sql_admin_password` | The generated admin password (marked `sensitive`) — consumed by the `key-vault` module's `sql_admin_password` input |
| `db_id` | ID of the database resource |

## Known, deliberately deferred hardening

SQL Server extended auditing (a real Trivy finding) requires a dedicated storage account as an
audit-log destination, which doesn't exist yet — treated as separate future work rather than
folded into this module under time pressure. See `CHALLENGES.md`.

## Example usage

```hcl
module "database" {
  source = "../../modules/database"

  resource_group_name = azurerm_resource_group.main.name
}
```
